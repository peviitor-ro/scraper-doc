# Security Policy

## Scope

This repository contains documentation and examples for peviitor.ro scrapers. It does not run in production and should not contain credentials, API keys, tokens, passwords, CVs, candidate data, or other personal data.

## Supported versions

Only the `main` branch is maintained. Please make sure you are reading the latest version of a document before reporting an issue.

## Reporting a vulnerability

Please **do not** open a public issue for a security problem. If you are unsure whether your question is sensitive, use one of the private channels below.

Report it privately instead:

- Email **aocpeviitor@gmail.com**, or
- Use GitHub's private vulnerability reporting on this repository, if available, or
- Contact one of the maintainers listed in [README.md](README.md#maintainers-and-contact).

Include:

- The affected file or link.
- What the problem is and why it is risky.
- Steps to reproduce, if applicable.
- Any relevant error message, with secrets removed.

We will review the report and coordinate a fix and disclosure with you.

## Leaked credentials

If a real key, token, or password is committed anywhere in the peviitor.ro organization:

1. Revoke or rotate it immediately.
2. Contact the maintainers privately.
3. Do not include the secret in a public issue, pull request, or commit message.

## Documentation rules

When contributing to this repo:

- Never add real API keys, tokens, passwords, or credentials.
- Never add CVs, candidate names, emails, phone numbers, or other personal data.
- Use clearly fictional company names and CUI/CIF values in examples.
- Keep GDPR guidance aligned with [16 — GDPR and data minimization](16-gdpr-data-minimization.md).
