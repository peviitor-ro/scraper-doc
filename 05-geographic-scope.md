# 05 — Geographic scope

We focus on jobs that can be performed in Romania, including remote roles open to candidates located in Romania.

When the careers page provides a location, use Romanian city or county names with diacritics where possible, for example `București` or `Cluj-Napoca`. Location is optional in the [job model](https://github.com/peviitor-ro/peviitor_core#job-model-schema), but accurate locations improve search quality.
