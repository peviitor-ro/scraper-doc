# 19 — Questions and Answers

## Ask anything

If you are a scraper volunteer and something is unclear, open a new [GitHub Issue](https://github.com/peviitor-ro/scraper-doc/issues/new/choose) and ask. There are no silly questions: the more questions we collect, the clearer these guidelines become.

Before opening a new issue, you can also [browse existing questions](https://github.com/peviitor-ro/scraper-doc/issues).

## What happens next

1. A maintainer answers in the issue.
2. The answer is added to the relevant Markdown file in this repo, or to this file if it is a general question.
3. The issue stays as the audit trail that explains why the documentation changed.

## How to ask a useful question

- Say which doc and section, or which step, you are following.
- Say what you expected and what actually happened.
- Paste the exact error message or the wording that was unclear.
- Include the language/runtime and OS if they matter.
- Remove API keys, tokens, passwords, CVs, candidate data, and other personal data from examples.

The [question issue template](https://github.com/peviitor-ro/scraper-doc/issues/new/choose) asks for these details for you.

## Where to ask

- [Open a new question issue](https://github.com/peviitor-ro/scraper-doc/issues/new/choose)
- [See all issues](https://github.com/peviitor-ro/scraper-doc/issues)

## Private and security matters

Do **not** open a public issue for security problems, leaked credentials, or anything involving personal data. Use [SECURITY.md](SECURITY.md) instead. If you are unsure whether a question is sensitive, use the private contact options there.
